# 公開ファイル投入口

ここへ Markdown（`.md`）または HTML（`.html`）を入れた後、次のように依頼してください。

> inbox に入れたファイルを公開してください。

画像やダウンロードファイルが付属する場合は、記事ごとにサブフォルダへまとめます。

```text
inbox/
├── article.md
└── another-article/
    ├── draft.html
    ├── figure-1.png
    └── data.csv
```

- サブフォルダ1つを1ページとして扱います。
- サブフォルダ内の中心となる `.md` または `.html` は、原則1つにしてください。
- ファイル名は日本語でも構いません。公開時に内容からURL名を決めます。
- 認証情報、個人情報、公開できないデータは置かないでください。
- この `README.md` 自体は処理対象外です。
